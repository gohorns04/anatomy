# 몸 탐험 v2: 여성 장기, 연결된 구조물, 검색, 부위 바로가기, 이름표, 단면

v1 설계(`2026-11-17-anatomy-3d-design.md`) 위에 기능을 더한다. v1의 목표·안티 목표·제약은 그대로 유효하다.

## 의도
- 사용자는 일반 교양 목적으로 쓰지만, 전문 해부학 앱에 가까운 탐험 경험을 원한다.
- 이번 요청: 남녀 선택, 오른쪽 패널 정리(글자 축소, 위아래 분할, 아래 칸에 다른 정보), 벤치마킹 기능 4개(검색, 부위, 이름표, 단면).

## 사용자가 정한 것
1. 여성 장기를 추가한다. 무료 데이터만 쓴다.
2. 패널 아래 칸은 **연결된 구조물**(A안)로 채운다.
3. 검색, 부위 바로가기, 이름표, 단면을 추가한다.
4. 글자 크기를 줄인다.

## 비목표
- 여성 전신 모델(여성 근육·뼈 형태). 무료 데이터가 없다.
- 질환 정보, 퀴즈, 계정, 의학 조언.
- 단면의 단면 채우기(잘린 면을 색으로 메우기)와 세로·옆 방향 단면. 가로 단면 하나만 한다.
- 근육 움직임 애니메이션, 이야기 투어(다음 후보).

## 안티 목표
- 여성 장기가 엉뚱한 곳에 떠 있거나 골반 밖으로 튀어나오는 것.
- 이름표가 화면을 덮어 모델이 안 보이는 것.
- 아이폰에서 기능 추가로 느려지는 것.

## 1. 남·여 선택

### 데이터 (조사 결과, 2026-11-18)
- Z-Anatomy와 BodyParts3D는 남성뿐이다.
- 미국 NIH Human Reference Atlas(HRA) v1.2 3D 장기 모델은 CC BY 4.0이다. 출처는 Visible Human 여성 데이터다. 쓸 파일(GitHub `hubmapconsortium/ccf-releases` `v1.2/models`):
  - `VH_F_Uterus.glb` (0.9MB)
  - `VH_F_Ovary_L/R.glb`
  - `VH_F_Fallopian_Tube_L/R.glb` (각 0.3MB)
  - `VH_F_Urinary_Bladder.glb` (0.8MB)
  - `VH_F_Pelvis.glb` (1.6MB, 정렬 기준용)
  - `VH_F_Skin.glb` (23MB, 정렬이 맞을 때만 사용)
- 받기 전에 각 파일의 라이선스 표기를 다시 확인한다. 출처 문구: "Human Reference Atlas 3D Reference Objects, HuBMAP/NIH, CC BY 4.0".

### 동작
- 상단에 "남 / 여" 전환을 둔다. 기본값은 남이다.
- **여**로 바꾸면:
  - 장기층에서 남성 생식기관(전립샘, 고환, 음경, 정낭, 정관 등 Z-Anatomy의 남성 생식계 메시)을 숨기고, HRA의 자궁, 난소, 자궁관, 여성 방광을 보인다.
  - 남성 방광은 숨긴다.
  - 피부층은 HRA 여성 피부를 쓴다. 단, 정렬 검증을 통과할 때만이다. 통과하지 못하면 피부는 공통으로 두고 사용자에게 알린다.
  - 근육·뼈·신경·혈관은 공통이다. 정보 화면에 "여성 모드는 골반 장기(와 피부)만 바뀌어요"라고 밝힌다.
- 정렬: HRA 여성 골반 뼈의 경계 상자를 Z-Anatomy 골반(볼기뼈+엉치뼈)의 경계 상자에 맞추는 균일 스케일과 이동을 구하고(`tools/align.py` 재사용), 여성 장기 전체에 적용한다. 앞뒤·좌우 축 방향은 v1처럼 기준 뼈로 판정한다. 결과는 렌더 이미지로 눈으로 확인한다.
- 변환 결과: `model/female.glb`(장기). 피부를 통과시키면 `model/skin-female.glb`도 만든다. 메시 이름은 `Uterus`, `Ovary.l`/`Ovary.r`, `Uterine tube.l`/`.r`, `Urinary bladder (female)`, `Skin (female)`이다.
- `index.json`의 항목에 `sex: "male" | "female"`을 추가한다. 공통 메시는 이 필드가 없다. 남성 생식계 메시에는 `"male"`이 붙는다.
- 한국어 내용을 추가한다: 자궁, 난소, 자궁관(나팔관), 전립샘, 고환.

## 2. 오른쪽 패널

- 글자 크기를 한 단계 줄인다. 제목 1.5→1.25rem, 본문 1→0.875rem, 표 0.9375→0.8125rem.
- 넓은 화면에서는 패널을 위아래로 나눈다. 위 약 60%는 설명(지금 내용), 아래 약 40%는 **연결된 구조물**이다. 칸마다 따로 스크롤된다.
- 세로 휴대폰 시트에서는 설명 아래에 이어서 보인다.
- **연결된 구조물:**
  - 한국어 내용이 있는 항목에는 `related` 필드를 둔다. 형식은 `[{ "type": "신경"|"뼈"|"혈관"|"근육"|"장기", "bases": [...] }]`이다.
    - 근육: 지배 신경, 이는곳·닿는곳 뼈, 주된 혈관
    - 뼈: 붙는 주요 근육, 관절을 이루는 뼈
    - 장기·혈관·신경: 인접·연결 구조
  - 각 줄은 한국어 이름(내용이 있으면)이나 영어 이름으로 보여 준다.
  - 누르면 그 구조물을 선택하고 "가까이 보기"한다. 꺼진 층이면 그 층을 불러와 켠다.
  - 내용이 없는 구조물은 같은 묶음(group)의 다른 구조물을 최대 8개 보여 준다. 제목은 "같은 부위의 구조물"이다.
  - 아무것도 선택하지 않았을 때 아래 칸은 비우고, "구조물을 고르면 연결된 신경·뼈·혈관이 여기 나와요"라고 안내한다.

## 3. 검색
- 상단에 돋보기 버튼을 두고, 누르면 입력창이 열린다.
- 대상: 한국어 이름(괄호 속 한자어 포함), 영어 이름, 라틴어 이름, 모든 메시의 영어 base 이름.
- 순서: 완전 일치 → 앞부분 일치 → 포함, 한국어 내용이 있는 항목이 먼저다. 결과는 최대 20개다.
- 한글 초성 검색(예: "ㅇㄷㄱ" → 위팔두갈래근)을 지원한다.
- 결과를 고르면 연결된 구조물과 같은 동작(층 켜기 → 선택 → 가까이 보기)을 한다. 좌우가 있으면 오른쪽을 고른다.

## 4. 부위 바로가기
- 버튼: 머리, 목, 가슴, 배, 골반, 팔, 손, 다리, 발, 등.
- 각 버튼은 정해 둔 카메라 시점(바라보는 점, 거리, 방향)으로 부드럽게 이동한다. "등"은 뒤에서 본다.
- 넓은 화면에서는 모델 영역 왼쪽 아래에 세로로 놓는다. 세로 휴대폰에서는 층 버튼 아래 둘째 줄에 가로 스크롤로 놓는다.

## 5. 이름표
- 상단에 "이름표" 켜기/끄기를 둔다. 기본은 끔이다.
- 켜면 한국어 내용이 있는 구조물 중 다음 조건을 만족하는 것의 이름을 화면에 띄운다.
  - 지금 켜진(`on`) 층에 있다.
  - 숨겨지지 않았다.
  - 중심이 화면 안에 있다.
- 겹침 방지: 화면 중앙에 가까운 것부터 놓고, 이미 놓인 이름표와 겹치면 뺀다. 최대 24개다.
- 카메라가 움직이면 다시 계산한다. 계산은 프레임당 1회까지, 움직이는 동안은 100ms마다다.
- 이름표를 누르면 그 구조물을 선택한다.
- 가려진 구조물(앞에 다른 구조물이 있음)은 중심점 한 번의 레이캐스트로 판정해서 뺀다.

## 6. 단면
- 상단에 "단면" 켜기/끄기를 둔다. 켜면 모델 영역 아래에 가로 슬라이더(발 ↔ 머리)가 나타난다.
- 슬라이더 높이보다 위쪽을 잘라 낸다. three.js `clippingPlanes`를 쓰고, 모든 재질에 같은 평면을 적용한다. 잘린 메시는 안쪽 면도 보이게 양면 렌더한다.
- 잘린 면을 색으로 채우지는 않는다(비목표).
- 탭 선택은 잘려 나간 부분을 무시한다(레이캐스트 결과가 평면 위면 건너뜀).

## 테스트와 확인
- 순수 로직은 Node 테스트로 확인한다: 검색 순위·초성, 연결 목록 만들기, 이름표 배치(겹침), 부위 프리셋 값 검증, 단면 레이캐스트 필터, 성별 표시 규칙.
- 정렬은 렌더 이미지와 경계 상자 수치로 확인한다.
- 화면은 넓은 화면과 세로 휴대폰 크기 브라우저에서 확인한다.
- 아이폰 실기기에서는 사용자가 부드러움을 확인한다.

## 빌더 검토에서 나온 결정 (내 판단)
- **남성 전용 메시의 범위:** 여성 모드에서 숨기는 남성 전용 메시는 이름 규칙으로 정하고 테스트로 고정한다.
  - 장기층의 남성 생식계 묶음 전체(전립샘, 고환, 부고환, 음경, 정낭, 정관, 사정관 등)와 남성 요도(Urethra)
  - 혈관층의 고환·음경 동정맥(이름에 testicular, penis, penile, scrotal이 들어간 것)
  - 근육층의 고환올림근(cremaster)
  - 회음 근육(망울해면체근 등)은 여성에게도 있으므로 공통으로 둔다.
  - HRA에 여성 요도가 없어서 여성 방광은 아래로 이어지지 않는다. 정보 화면에 이 한계를 밝힌다.
- **다른 성별의 구조물:** 검색과 연결된 구조물에는 모두 보인다. 다른 성별 전용 구조물을 고르면 성별을 자동으로 바꾼 뒤 층 켜기 → 선택 → 가까이 보기를 한다. 이름표는 현재 성별에서 보이는 것만 띄운다.
- **여성 모드의 피부 (사용자 확인 필요):** HRA 여성 피부는 다른 사람의 몸이라 골반만 맞춰서는 머리·어깨·손발이 맞지 않는다. 현재 피부(남성)는 외부 생식기를 포함한다. 그래서 여성 피부는 쓰지 않는다. 여성 모드에서는 피부층 버튼을 비활성화하고 "여성 모드에서는 피부층을 지원하지 않아요"라고 안내한다. 이 경우 `VH_F_Skin.glb`(23MB)는 받지 않는다.

## 빌더에게 맡기는 것
- 각 `related` 목록의 구체적 내용(해부학적으로 정확해야 함), 부위 프리셋 수치, 버튼 아이콘과 배치 세부, 이름표 모양.
